# Publishing

There are several ways to publish Inspect Viz content, ranging from PNG images suitable for embedding in documents all the way up to notebooks, websites, and dashboards.

|  |  |
|----|----|
| [Plots](publishing-plots.html.md) | Publishing standalone plots as PNG images or HTML snippets. |
| [Notebooks](publishing-notebooks.html.md) | Publish collections of plots and tables as a notebook. |
| [Websites](publishing-websites.html.md) | Embed plots and tables in a larger website. |
| [Dashboards](publishing-dashboards.html.md) | Create a dashboard to provide easy navigation of collections of plots. |
| [PNG Output](publishing-png-output.html.md) | Rendering plots as PNG images within notebooks, websites, and dashboards. |
